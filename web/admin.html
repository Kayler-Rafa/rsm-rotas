O que importa mais

Rota recomendada

Todos os números são estimativa. A coleta de dados não identificou feed GTFS aberto nem API de tempo real para os ônibus da RMR: os tempos de espera são penalidades fixas de transferência, não a espera efetiva.

Composição da viagem

    Fronteira de Pareto calculada uma única vez pelo algoritmo de Martins. Cada perfil apenas reordena este mesmo conjunto por TOPSIS — nenhum recálculo do grafo por usuário. Clique em uma linha para vê-la no mapa.

    Para cada modal, a melhor viagem possível usando somente ele mais a caminhada, nas condições que você escolheu. Isolar o modal é o que responde "isso dá conta deste trajeto?" — em vez de deixá-lo aparecer como uma perna de 500 m dentro de uma rota mista.

    Varia uma condição por vez a partir das suas opções atuais, para isolar o efeito de cada uma sobre a rota ótima.

    Compara a fronteira exata (Martins) com a aproximada (NSGA-II) sobre a mesma instância. O NSGA-II leva alguns segundos.
